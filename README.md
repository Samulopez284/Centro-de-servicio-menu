## Publicar en GitHub Pages

Este proyecto ya esta listo para publicarse como pagina estatica.

Archivo principal:
- `index.html`

Pasos rapidos:

1. Crea un repositorio nuevo en GitHub, por ejemplo `tecniya-menu`.
2. Sube el contenido completo de esta carpeta al repositorio:
   `C:\Users\samyl\OneDrive\Documentos\kiron 2\Nueva carpeta\.vscode\menu-gh-pages`
3. En GitHub abre `Settings` -> `Pages`.
4. En `Build and deployment`, elige:
   `Source` = `Deploy from a branch`
5. Selecciona:
   `Branch` = `main`
   `Folder` = `/ (root)`
6. Guarda y espera 1 o 2 minutos.
7. Tu link quedara asi:
   `https://TU-USUARIO.github.io/tecniya-menu/`

Notas:
- GitHub Pages es gratis.
- Como el archivo principal se llama `index.html`, abrira directo al entrar al link.
- Si despues cambias el menu, solo reemplaza `index.html` y vuelve a subir los cambios.
